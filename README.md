# Ta’lim sifatini oşiriş loyihasi — GitHub Pages

## Fayllar
- `index.html` — bosh sahifa
- `problem1/` … `problem6/` — har bir muammo alohida sahifada
- `akaboyev/`, `manbalar/`, `qr/` — yordamçi sahifalar
- `assets/style.css`, `assets/script.js`, `assets/img/` — umumiy resurslar
- `404.html`, `robots.txt`, `sitemap.xml`, `.nojekyll`

## Nashr qiliş
1. GitHub’da `talimloyihasi` nomli repository yarating.
2. ZIP ichidagi fayl va papkalarni repository ildiziga, papka tuzilishini saqlagan holda yuklang.
3. Settings → Pages → Deploy from a branch → `main` / `(root)` ni tanlang.
4. Bir neça daqiqa kutib, https://alisaidm.github.io/talimloyihasi/ manzilini oçing.

## Eslatma
Manba DOCX faylida manba sarlavhalari bor, lekin URL/domenlar yo‘q. Saytda noto‘g‘ri havolalar uydirilmagan. Isomiddin Akaboyev haqidagi tarjimai hol, yutuqlar va Instagram video URLlari ham taqdim etilmagan; tegishli joylar aniq tahrirlanadigan placeholder sifatida qoldirilgan. QR tasviri tashqi QR API ishlatmasdan lokal ravishda yaratilgan.
